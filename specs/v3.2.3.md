# v3.2.3 — Back button and sign-out navigation fixes

**Status:** Complete.

## Scope

### Player-facing

- **Android back** — works on game hubs, stats, settings, and play screens; blocked only on platform home so users cannot return to the launch loader
- **Sign-out** — goes straight to the welcome screen with no brief flash of platform home

### Engineering

- Platform home registers `BackHandler` inside `useFocusEffect` so the listener is removed when home is not focused
- Profile menu awaits `signOut()` and `clearGuest()` before `router.replace('/')`

## Acceptance criteria

- [x] Word Hunt hub → stats → Android back returns to hub
- [x] Platform home → Android back does not return to welcome/loader
- [x] Sign out → welcome screen without intermediate home flash

## Out of scope

- Double-back-to-exit on platform home
