# v3.2.2 — Sign-out speed and auth navigation

**Status:** Complete.

## Scope

### Player-facing

- **Sign-out** — returns to the welcome screen immediately; cloud sync continues in the background
- **After sign-in** — Android back from home no longer lands on a loading screen with no way to sign in again
- **Auth navigation** — successful sign-in resets the stack so home is the root screen

### Engineering

- `pushSnapshotWithTimeout` — best-effort cloud push (2s cap) on sign-out without blocking UI
- `navigateToHome` — `dismissAll()` + `replace('/home')` after auth success
- Welcome uses `Redirect` when session or guest mode is active; auth routes use `replace` from welcome
- Home consumes Android hardware back press

## Acceptance criteria

- [x] Tap Sign out → welcome screen appears without waiting on network
- [x] Sign in → home → Android back does not show welcome loading trap
- [x] Welcome → Sign in with email → sign in → home is root of stack
- [x] Cloud push on sign-out still attempted in background before session ends

## Out of scope

- Double-back-to-exit on home
- Settings-scoped storage (same device-global pattern as before v3.2.1 stats fix)
