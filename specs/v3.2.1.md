# v3.2.1 — Stats sync fix

**Status:** Complete.

## Scope

### Player-facing

- Signed-in stats stay accurate when switching between guest and multiple accounts on one device
- Sign-in no longer doubles or inflates games played, wins, or streaks in cloud sync

### Engineering

- Account-scoped stats in local storage (`guest` vs `user/{id}`)
- `mergeGuestWordHuntStats` / `mergeGuestGridSnapStats` — additive merge of guest progress into cloud on sign-in only
- `pickNewerWordHuntStats` / `pickNewerGridSnapStats` — cold start and re-login without re-summing
- `resetGuestStats` after sign-in merge; `loadSignedInUserStores` on app launch when session exists

## Acceptance criteria

- [x] Guest stats stored separately from each signed-in account on device
- [x] Sign-in merges guest stats into cloud once, then clears guest game counts
- [x] Re-sign-in to same account does not add cloud totals to themselves again
- [x] Switching accounts does not bleed one account's stats into another
- [x] Signed-in cold start loads user stats from cloud or newer local cache

## Notes

Cloud rows inflated before this release must be reset manually in Supabase. The app prevents future inflation only.
