# v3.3 — Game timers and mode-segregated stats

**Status:** Planned.

## Scope

### Player-facing

- **In-game timer** — Word Hunt and Grid Snap show elapsed time (mm:ss) at the top of the play screen while a puzzle is active; timer pauses on win/loss
- **Time stats** — each stats screen shows fastest, average, and slowest solve time for the selected mode
- **Mode-segregated stats** — stats are tracked and viewed per game mode:
  - **Word Hunt:** Daily, Practice, Custom
  - **Grid Snap:** Easy, Medium, Hard
- **Stats screen picker** — dropdown (or equivalent) on each game's stats screen to switch modes; summary cards and time stats update for the selected mode
- **Cloud sync** — per-mode stats and time records sync when signed in (guest stays local)

### Engineering

- Restructured stats stores: per-mode buckets for games played, wins, streaks, guess distribution (Word Hunt), and time aggregates
- SQL migration `004_mode_stats.sql` — JSON columns or normalized fields for per-mode stats on `word_hunt_stats` and `grid_snap_stats`
- Updated `mergePolicy` — merge per-mode stats independently (sum counts, max streaks, min fastest, weighted average for average time)
- Timer hook shared by both play screens; elapsed seconds recorded on game end
- Custom puzzle games count toward **Custom** mode stats only (not Daily or Practice)

## Acceptance criteria

### In-game timer

- [ ] Word Hunt play screen shows elapsed mm:ss while the puzzle is in progress
- [ ] Grid Snap play screen shows elapsed mm:ss while the puzzle is in progress
- [ ] Timer stops when the game ends (win or loss) and does not keep running on the end screen
- [ ] Resuming an in-progress game continues the timer from elapsed time saved with the session (or restarts fairly — pick one and document in [experience.md](./experience.md))

### Word Hunt stats by mode

- [ ] Stats screen has a mode picker: Daily, Practice, Custom
- [ ] Played, win %, current streak, max streak, and guess distribution reflect the selected mode
- [ ] Daily win updates Daily stats only; practice updates Practice; custom puzzle updates Custom
- [ ] Fastest, average, and slowest time shown for the selected mode (hidden or em dash when no completed games)

### Grid Snap stats by mode

- [ ] Stats screen has a mode picker: Easy, Medium, Hard
- [ ] Played, win %, streaks reflect the difficulty of the puzzle played (not the user's current default difficulty setting)
- [ ] Fastest, average, and slowest time shown per difficulty

### Sync

- [ ] Signed-in user sees merged per-mode stats after sign-in on a second device
- [ ] Guest per-mode stats remain device-local
- [ ] Sign-out does not corrupt per-mode buckets for guest or the next signed-in user

### Migration

- [ ] Existing users' legacy aggregate stats migrate into **Daily** (Word Hunt) and **Easy** (Grid Snap) buckets, or an **All** rollup policy documented in migration notes — default: map existing totals to Daily / Easy so nothing is lost

## Out of scope

- Move-count stats for Grid Snap (see [backlog.md](./backlog.md))
- Leaderboards
- Share completed puzzle image

## Data model (engineering)

Per-game local and cloud shape (conceptual):

```ts
type TimeAggregates = {
  fastestSec: number | null;
  slowestSec: number | null;
  totalSec: number;
  completedCount: number; // for average = totalSec / completedCount
};

type WordHuntModeStats = StatsData & { time: TimeAggregates };
type WordHuntStatsByMode = Record<'daily' | 'practice' | 'custom', WordHuntModeStats>;

type GridSnapModeStats = GridSnapStatsData & { time: TimeAggregates };
type GridSnapStatsByMode = Record<'easy' | 'medium' | 'hard', GridSnapModeStats>;
```
