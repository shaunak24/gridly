# v4.0.1 — Daily reminder defaults

**Status:** Complete.

## Scope

### Player-facing

- **Daily reminders** — all three games default to **on** with staggered times: Word Hunt **8:00 AM**, Grid Snap **8:30 AM**, Color Flow **9:00 AM** (device local time)
- Fixes unset reminder time displaying as **12:00 AM** before the user configured a time

### Engineering

- `GAME_REMINDER_DEFAULTS` in `notifications.ts` as single source of truth per game
- `parseReminderHour` / `parseReminderMinute` treat `null` and empty string as unset (avoids `Number(null) === 0`)
- Settings stores seed local storage on first hydrate when reminder keys are missing
- Cloud repository uses per-game defaults; notifications default on unless explicitly disabled

## Acceptance criteria

- [x] Fresh install shows reminders on with correct per-game default times
- [x] Unset stored reminder hour does not display as 12:00 AM
- [x] Existing explicit user preferences (off or custom time) are preserved
- [x] Unit tests cover reminder parsing and Grid Snap hydrate defaults

## Out of scope

- Migrating installs that already saved midnight (`0:00`) from the prior bug
