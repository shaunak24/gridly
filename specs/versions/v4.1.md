# v4.1 — Color Flow correctness and drag feel

**Status:** Complete.

## Scope

### Player-facing

- **Hard mode no longer freezes the app** — generating an 8×8 board used a backtracking search that could take seconds each, and the hub builds five at once, so entering hard practice or daily hung and sometimes crashed
- **Connected flows lock** — once a path reaches its matching dot it cannot be extended further. Previously the line kept growing past the dot, inflating the fill count and, with every pair connected, letting one color scribble over the rest of the grid for a false win
- **No more colour hijacking** — the colour is locked when you touch down, so dragging one flow across another colour's dot no longer abandons your line and starts theirs
- **Fast drags keep up** — skipped cells between touch samples are filled in along an orthogonal route instead of silently killing the drag
- **Steadier hit-testing** — a finger resting on a cell boundary no longer flickers between two cells, and touch coordinates now line up exactly with the grid
- **Grab a flow anywhere** — touching a drawn cell picks up that colour and trims to it; touching either dot restarts that colour from there
- **Reset board** — clears every flow on the current puzzle without changing the puzzle or the timer
- **Haptics** — a tick when you grab a dot, a thump when a pair connects, a flourish on solving
- **Clearer board** — drawn cells carry a faint tint of their colour, connected pairs' dots are marked done, and the status pill reads `Cells: 47/64` instead of a rounded percentage
- Replaced the grey flow colour, which read as disabled, with sky blue
- **Home screen order** — Color Flow, then Grid Snap, then Word Hunt
- **Faster end-of-game modal** — 2s → 1.1s across all three games, so a finished board is still readable without the wait

### Engineering

- `buildHamiltonianPath` replaced: a snake ordering shuffled by backbite moves, which is linear time and cannot fail, instead of exponential-worst-case DFS backtracking. 25 hard boards went from ~10s to ~30ms; the retry loop drops from 40 attempts to 8
- `applyPathStep` refuses to append once `isPairConnected`; backtracking still reopens the path
- `cutOtherPathsAtCell` now cuts the victim *before* the crossed cell, so a cell is never claimed by two colours
- `updatePath` requires an endpoint start and stops at the opposite endpoint
- `sanitizeSavedPaths` repairs boards persisted by v4.0, which could hold over-extended or double-claimed paths; applied on load only, never in `recomputeState`
- New pure engine helpers: `interpolateCells`, `applyPathSteps`, `applyDragTo`, `beginDragAt`, `resolveTouchCell`, `isInsideBoard`, `pathOwnerAt`, `filledCellCount`, `buildPathColorMap`, `clearColor`, `resetBoard`
- Store gains a stroke lifecycle — `beginDrag` / `extendDrag` / `commitDrag` / `resetBoard` — replacing per-point `applyPoint`. Rejected steps skip `set()` entirely, and persistence runs once per stroke instead of once per pan event (which also did two AsyncStorage reads each)
- `FlowBoard` measures the grid rather than the bordered frame, locks the colour in a ref across `runOnJS` callbacks, dedupes repeated cells, and is memoised
- `play.tsx` uses per-field store selectors so the 1 Hz timer tick no longer re-renders the board
- New `src/shared/utils/haptics.ts` wrapper over `expo-haptics`, no-op on web and failure-tolerant
- `GAMES` order in `gameRegistry.ts` drives the home list; `GAME_END_MODAL_DELAY_MS` lowered to `1100`, picked up by every game through `useGameEndFlow`

## Acceptance criteria

- [x] Hard mode opens without a freeze from either the hub or a difficulty switch
- [x] A connected flow cannot be extended; backtracking off the second dot reopens it
- [x] Connecting every pair then scribbling cannot fill the grid or trigger a win
- [x] No cell is ever claimed by two colours after a crossing
- [x] A fast drag across several cells follows an orthogonal route with no dropped cells
- [x] Dragging across another colour's dot does not switch the active colour
- [x] A v4.0 save with an over-extended path loads truncated and playable
- [x] Reset clears the board without resetting the timer or the puzzle
- [x] Unit tests cover the completion guard, cut semantics, interpolation, begin semantics, hit-testing, and the save sanitizer

## Out of scope

- Per-colour clear control (tapping either dot already restarts that flow)
- Animated path drawing or rounded path caps
- Haptics intensity settings
