# v4.0

## Goal

Add **Color Flow** as Gridly's third grid-based game: connect matching colored endpoints with orthogonal paths and fill the entire board.

## Status

**In development**

## Features

### Color Flow (new)

- [x] Game hub at `/games/color-flow` with daily, practice, stats, how to play, settings
- [x] Play screen with path drawing, coverage status, and in-game timer
- [x] Difficulty: Easy 4×4, Medium 6×6, Hard 8×8 (default difficulty in settings)
- [x] Daily puzzle from curated bank (seeded by date + difficulty)
- [x] Practice puzzles from curated bank with optional procedural fallback
- [x] Stats by difficulty (Easy / Medium / Hard) with solve-time aggregates
- [x] Daily reminder toggle and time picker
- [x] Cloud sync for stats, settings, and daily completion
- [x] `ColorFlowIcon` on platform home and game hub

### Engineering

- [x] Pure TypeScript `flowEngine` with unit tests
- [x] Zustand stores: `colorFlowStore`, `colorFlowStatsStore`, `colorFlowSettingsStore`
- [x] Supabase migration `006_color_flow.sql`
- [x] Platform wiring: registry, sync, notifications, boot hydration

## Out of scope (v4.0)

- Custom puzzles and share invites
- Daily win share to clipboard
- Interactive tutorial (static how-to-play only)
