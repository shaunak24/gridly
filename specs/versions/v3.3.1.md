# v3.3.1 — Stats mode picker contrast and sign-out persistence

**Status:** Complete.

## Scope

### Player-facing

- **Stats mode picker** — selected mode uses coral highlight on a darker track so Daily / Practice / Custom (and Grid Snap difficulties) are readable in dark mode
- **Sign-out / sign-in** — stats and daily completion restore for the same account after signing back in

### Engineering

- `ModePicker` uses `keyDefault` track and coral selected chip (dark `card` and `tileEmpty` were identical)
- `handlePostSignIn` loads account stats on re-login; `mergeLocalToCloud` only when guest has played
- Stats persist to **guest** AsyncStorage on each game end; signed-in accounts **push to cloud** on each update (`pushIfSignedIn`) and refresh the per-user offline cache from that push
- `hasGuestStatsProgress` helper; `resetPostSignInState` on sign-out

## Acceptance criteria

- [x] Stats mode picker selected state is clearly visible in dark mode
- [x] Sign out → sign in (same account) → stats and daily lock match pre-sign-out state
- [x] Guest → first sign-in still merges guest progress into cloud

## Out of scope

- Cross-device sync when cloud push fails on sign-out (best-effort push unchanged)
