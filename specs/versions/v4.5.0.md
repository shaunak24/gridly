# v4.5.0 — Color Flow level campaign

**Status:** Complete.

## Scope

Introduce a 100-level **Flow Path** campaign as Color Flow's primary mode, with a scrollable path map, gradually increasing puzzle specs, and season-ready data. Daily and Practice remain as secondary modes.

## Player-facing

### Flow Path (campaign)

- [x] Hub primary CTA opens **Flow Path** journey map (`/games/color-flow/journey`)
- [x] Season 1: 100 levels with gradually increasing grid size, pair count, and time limit
- [x] Journey map shows completed, current, and locked levels on a winding path
- [x] Tap unlocked level to play or replay; sticky **Play Level N** for current frontier
- [x] Win unlocks next level; loss allows retry without blocking progress
- [x] Campaign session persists across app restart and hub navigation
- [x] Win end bar: **Next level** (when applicable) and **Back to map**; loss: **Try again** and **Back to map**
- [x] Virtualized map for fast load; puzzle pre-starts before play screen opens
- [x] **Next level** advances in-place (no navigation stack buildup)

### Daily and Practice

- [x] Daily uses fixed medium-tier puzzle (6×6, 4 pairs) — independent of settings
- [x] Practice uses **Practice difficulty** from settings (Easy / Medium / Hard)
- [x] Daily streak and notifications unchanged; practice does not affect streak or campaign unlock

### Stats

- [x] **Flow Path** block: levels completed, current level, progress %
- [x] Daily and practice-by-difficulty blocks unchanged

### Platform

- [x] Android hardware back uses parent-route `replace` (not history pop) so repeated play sessions do not stack

## Engineering

- [x] `levelCurve.ts`, `levelBank.ts`, `seasons.ts`, `generateBoardFromSpec`
- [x] `colorFlowCampaignStore`; campaign progress in `ColorFlowStoredStats.campaign` (cloud sync via existing jsonb)
- [x] `FlowPathMap` journey UI (FlatList); `campaign` play mode and saved session key
- [x] Specs, changelog, version bump to 4.5.0
