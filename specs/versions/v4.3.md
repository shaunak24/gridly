# v4.3 — Daily streaks, time limits, UX polish

**Status:** Complete.

## Scope

### Player-facing

- **Grid Snap and Color Flow daily streak** — hub and stats show daily-challenge streak and played count only; practice no longer affects streak
- **Per-difficulty time limits** — countdown in the header; running out of time ends the game with the same loss modal flow as Word Hunt; daily locks after a time-up loss
- **Win %** — Grid Snap and Color Flow per-difficulty stats include losses (time-up)
- **Grid Snap image loading** — shared loading indicator while the puzzle image decodes
- **Word Hunt definitions** — when available from the dictionary API, a short definition appears on the win/loss end screen and modal (loaded in the background during play)
- **Android hardware back** — follows in-app hierarchy (e.g. stats → game hub → platform home), not browser-style history
- **Feedback tracking (admin)** — `implemented` boolean on `feedback` table for manual triage in Supabase (not used by the app)

### Time limits (seconds)

| Game | Easy | Medium | Hard |
|------|------|--------|------|
| Grid Snap | 300 | 420 | 600 |
| Color Flow | 300 | 120 | 300 |

### Engineering

- `DailyChallengeStats` + `daily` block in Grid Snap / Color Flow stored stats JSON; cloud `stats_by_mode` holds full payload `{ daily, byMode }`
- `recordGridSnapGameResult` / `recordColorFlowGameResult` with `mode` parameter
- `useGameTimeLimit`, `useHardwareBack`, `LoadingIndicator`, `useImageReady`
- `fetchWordDefinition` (Free Dictionary API over HTTPS)
- Migration `007_feedback_implemented.sql`

## Acceptance criteria

- [x] Practice wins/losses do not change daily streak for Grid Snap or Color Flow
- [x] Daily win increments daily streak; daily loss (including time-up) resets it and marks daily complete
- [x] Hub streak/played for Grid Snap and Color Flow match Word Hunt (daily bucket only)
- [x] Time-up shows loss modal and end bar; stats record a loss
- [x] Resuming a saved game past the time limit triggers immediate loss
- [x] Word Hunt shows definition when fetch succeeds; no extra latency on game end
- [x] Android back from game stats returns to that game’s hub, then hub back returns to platform home
- [x] Unit tests for daily stats recording and merge policy

## Out of scope

- Splitting Grid Snap / Color Flow stats into separate Daily vs Practice buckets (per-difficulty stats still mix both modes)
