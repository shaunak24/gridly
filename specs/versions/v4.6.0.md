# v4.6.0 — Ambient background music

**Status:** Complete.

## Scope

Add light, engaging ambient background music across the app with an app-wide toggle and subtle tempo increase during timed puzzle countdowns.

## Player-facing

- [x] Ambient music loops on platform home, game hubs, play screens, stats, settings, and feedback
- [x] Music does not play on welcome or auth screens
- [x] **Music** toggle in app settings (default on)
- [x] Music pauses when the app is backgrounded
- [x] Win/loss sounds duck music volume briefly
- [x] Grid Snap and Color Flow: music tempo increases below 60s and 30s remaining (same track, no hard cuts)

## Engineering

- [x] `backgroundMusic.ts` — single `createAudioPlayer` loop, volume ducking, playback-rate urgency
- [x] `BackgroundMusicHost` in root layout; `useBackgroundMusic` + `useMusicUrgency` hooks
- [x] `musicUrgency.ts` pure curve + unit tests
- [x] `assets/sounds/background-music.m4a` (Exploration Theme, CC0); procedural fallback via `npm run build:music`
- [x] `appSettingsStore.musicEnabled` persisted locally; cloud sync via `app_settings.music_enabled`
- [x] Supabase migration `008_app_settings_music.sql`

### Maintaining the loop

Regenerate or replace the background track: [tech-stack.md § Audio assets](../tech-stack.md#audio-assets) (`npm run build:music`, swap-in guide for licensed loops).

## Acceptance

1. Fresh install: music plays on platform home after guest continue or sign-in.
2. Toggle music off in settings — playback stops immediately; preference survives restart.
3. Grid Snap countdown below 60s — audible but subtle tempo increase (no track swap).
4. Win/loss modal — music ducks, win/loss tone audible, music restores.
5. Welcome screen — no music until user reaches home.
