# v4.4.0 — Grid Snap peek image hint

**Status:** In progress.

## Scope

### Player-facing

- **Grid Snap peek image** — while a puzzle is in progress, **Peek image** above the board shows the complete photo in a full-screen overlay for four seconds (tap **Got it** or the backdrop to close sooner). One use per puzzle; resuming a saved game remembers whether peek was already used. The countdown timer keeps running during the peek. In test mode, peek shows the solved numbered layout instead of a photo.

### Engineering

- `peekUsed` on `PersistedSnapGame` and `gridSnapStore`
- `ImagePeekOverlay`, `TestModeSolvedGridPreview`; `IMAGE_PEEK_DURATION_MS` in `peekHint.ts`

## Acceptance criteria

- [ ] **Peek image** appears above the grid while playing (daily and practice) once the puzzle is ready
- [ ] Overlay shows the full puzzle photo; auto-dismisses after ~4 seconds
- [ ] Button disappears after one use for that puzzle session
- [ ] Saved in-progress games restore `peekUsed` on continue
- [ ] Timer does not pause during peek
- [ ] Test mode peek shows the solved numbered grid layout

## Out of scope

- Multiple peeks with cooldown
- Pausing the timer during peek
- Stats or streak changes tied to peek usage
