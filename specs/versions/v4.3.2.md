# v4.3.2 — Google Play pre-release quality (Android)

**Status:** Complete.

## Scope

### Player-facing

- No visible feature changes. Closed-testing build addresses Google Play Console pre-release quality feedback from v4.3.1.

### Engineering

- **Android 15 BOOT_COMPLETED fix** — config plugin removes `BOOT_COMPLETED` boot actions from `expo-notifications` `NotificationsService` so Play static analysis no longer flags a conflict with `expo-audio` restricted foreground service types ([expo/expo#41627](https://github.com/expo/expo/issues/41627))
- **Game category manifest** — `android:appCategory="game"` declares Gridly as a game; portrait orientation lock remains intentional for phone-first puzzle UX and is exempt from large-screen orientation override requirements
- **Edge-to-edge deprecation notice** — Play Console advisory from React Native / `react-native-screens` transitive stack; no app code change in this release; revisit on Expo SDK upgrade

## Trade-offs

- Scheduled daily reminders are not rescheduled immediately after a device reboot until the user opens Gridly once. Acceptable for current reminder use case.

## Acceptance criteria

- [x] Config plugins registered in `app.json` (`withDisableNotificationsBootActions`, `withAndroidGameCategory`)
- [x] `app.json` / `package.json` version `4.3.2`
- [ ] EAS production build applies manifest changes (verified in Play Console pre-launch report after submit)
- [ ] Play-installed build: game-end sounds play; daily reminder can be scheduled and fires
- [ ] v4.3.2 submitted to closed testing (`alpha`) track without resetting 14-day tester clock

## Out of scope

- Removing portrait orientation lock or landscape layout support
- Upgrading Expo SDK solely to clear edge-to-edge deprecation warnings in Play Console
